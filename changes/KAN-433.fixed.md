- `install_local.py --uninstall` puts back a person's `settings.json` byte for byte when it held an empty section such as `"hooks": {}`.
- When `settings.json` was edited after the install, `--uninstall` still keeps the person's own empty sections and the file's CRLF line endings and byte-order mark.
- `install_local.py` prints `claude mcp add` with the server name before `--env` and `--header`, which take several values: `claude mcp add ... --env "KNOWLEDGE_REPO=$KNOWLEDGE_REPO" ai-dlc -- ...` read `ai-dlc` as a second variable and failed with `Invalid environment variable format`.
