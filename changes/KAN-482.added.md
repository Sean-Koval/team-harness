- `tests/test_guard_powershell.py` runs every shell guard as on Windows without Git Bash: Windows Python alone, with
  no git, bash or sh on PATH. Each guard lets an ordinary PowerShell call through, blocks a forbidden one with the
  reason it gives from Bash, and blocks a PowerShell call it can't read with exit 2, also through the installer's
  Windows hook command. The Windows CI job runs it.
