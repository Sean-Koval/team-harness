- `codify-lesson` skill (KAN-470): takes one open Lesson and proposes exactly one outcome, a Convention that cites
  the lesson as a records PR, a change to a shared skill, hook or guide fragment as a harness PR citing the lesson, or
  "not codifiable" with the reason written to the lesson. It drafts the follow-up that marks the lesson codified once
  the PR merges, never merges, and never codifies across a customer boundary. Three example lessons, one per outcome,
  in `tests/fixtures/codify-lesson/`.
