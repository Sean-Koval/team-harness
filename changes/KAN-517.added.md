- The artifact check (KAN-517): `.github/workflows/artifact-check.yml`, a reusable workflow a scaffolded repository
  calls on every PR. For an MCP server it starts the server over stdio, checks every tool's input schema and runs the
  golden calls in `evals/golden/`; for an agent or bot it runs `evals/tasks/*.yaml` under a hard budget and reports
  partial results when the budget runs out. It writes `artifact-check.json`, a receipt that validates against
  `actions/artifact-check/receipt.schema.json`, and a job summary. The MCP server template gains `tests/serve_fake.py`,
  its server on the fake backend, for the golden calls.
