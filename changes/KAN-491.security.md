- The shell guards now match a program name in any letter case (`Terraform.EXE apply`, `Kubectl delete`), as Windows
  and macOS find it; a database client's `-H` flag is still told apart from `-h`, the host.
- The work-system guard reads every PowerShell script block and parenthesis as the commands in it (`Invoke-Command`,
  `icm`, `% {...}`, `Start-Job`, `$sb = {...}`, nested blocks, `(gh ...)`, `$(gh ...)`, and a `param(...)` with its
  default values and validation scripts), and unwraps `iex('...')`, `-Command` and its short forms, and a string piped
  into `iex`. The unwrapping is one pass (KAN-491, the post-merge review of #40).
- The work-system guard judges each script file once per call state, reads words and scans hidden code in linear
  time, and blocks a call it can't judge within 5 s, or a command over 1 MB, well inside the hook's 10 s timeout:
  a hook killed at its timeout lets the call through.
- A comment no longer hides the commands after it: a quote inside a `#` comment opened a string in the guard's
  reading, and PowerShell's `<# ... #>` comments and the code in a double-quoted `$(...)` are read as PowerShell
  reads them.
