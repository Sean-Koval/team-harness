- The shell guards now match a program name in any letter case (`Terraform.EXE apply`, `Kubectl delete`), as Windows
  and macOS find it; a database client's `-H` flag is still told apart from `-h`, the host.
- The work-system guard reads every PowerShell script block as the commands in it (`Invoke-Command`, `icm`, `% {...}`,
  `Start-Job`, `$sb = {...}`, nested blocks, a leading `param(...)`), and unwraps `iex('...')`, `-Command` and its
  short forms, and a string piped into `iex`. The unwrapping is one pass, so a long call can't time the hook out
  (KAN-491, the post-merge review of #40).
