- The work-system hook guards an Atlassian server by its calls, whatever the server is named: a tool named for Jira,
  Confluence or Atlassian, any tool given an Atlassian site, and a router (`call_tool`, `use_tool`, Composio's
  multi-execute) naming an Atlassian operation or server are judged as tracker and wiki, every operation a router
  names is judged, and a session binding can only add roles, never take one away (KAN-459).
- On a tracker-bound server, a write that sets a status, state or resolution is refused like a transition; an MCP
  fetch that writes to Jira or Confluence over HTTP is refused as curl is; ai-dlc is recognised under another server
  name; and bindings the hook cannot read refuse every MCP call, with `sync_shared.py --check` reporting them.
- work-default names its Atlassian server `atlassian`, as suite-default does; its credential is
  `ATLASSIAN_MCP_AUTHORIZATION` (hangar credential `atlassian-mcp`). Skills reach Jira and Confluence by role
  (ai-dlc's `tracker_*` tools, or the tracker server), and a test keeps Atlassian tool names out of every skill.
  team-default keeps `jira`: it carries no work-system hook, and its candidate is the treated arm of a running
  flightdeck experiment.
- Upgrading a local work-default install: remove the old `jira` MCP server (`claude mcp remove jira`), add
  `atlassian` with the command `install_local.py` prints, and rename `JIRA_MCP_AUTHORIZATION` to
  `ATLASSIAN_MCP_AUTHORIZATION` (hangar credential `jira-mcp` to `atlassian-mcp`) wherever it was set.
- relock.py builds a lock's MCP servers from `bindings/<name>.yaml` when its servers declare a `transport` (with
  `endpoint`, or `command` and `args`), so adding, renaming or moving a server is a source change and the build
  writes the lock. suite-default and work-default declare theirs; team-default's lock keeps its own (KAN-459).
- A build from a clone without stable's release history refuses stable's environment, rather than stopping on a
  render error, when main's bindings no longer fit stable's lock (a renamed server) (KAN-459).
