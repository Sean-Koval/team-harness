- `scripts/doctor.py` is one readable preflight for a fresh work laptop or a new teammate: one `ok`, `fix` or `skip` line per check, each fix with its exact command, exit 1 on any fix and `--json` for hangar and flightdeck. It checks Claude Code against the lock's version (and, with `--live`, that the lock's model answers), the interpreter the hooks run with and PyYAML, that each installed hook runs and each guard blocks with exit 2, the install against its manifest, the installed lock against its channel, a clean checkout, one harness per scope, the guide's `@import` line and a real (not symlinked) `settings.json`, each lock MCP server in `claude mcp list` with the lock's endpoint (with `--live`, one `tools/list` call), `gh auth status` with repo scope on the company host, that the company's org overlay is applied, that the repository's test and check commands (`ai-dlc.toml` `[checks.commands]` or `--test-cmd`) are allowed, and that `hangar trace import` and `flightdeck ingest` are ready for local capture. It writes nothing and prints no credential value. The work-laptop runbook and README run it after the install.
