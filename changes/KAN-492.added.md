- The nightly capture batch runs once more per customer listed in the team repository's `[[transcripts.customers]]`,
  in that customer's own checkout (`repo_env`, default `KNOWLEDGE_REPO_<PROJECT>`): `work-copilot export --to` the
  checkout with `--scope project`, then filter, extraction and draft records PRs there (`propose --root`), with that
  checkout's own run log and state. A customer whose variable is unset or whose checkout does not declare
  `[repo] boundary = "customer"` and that `project` is skipped with a reason, never sent to the team repository. A team
  run never extracts a `boundary: customer` Source, and a customer run extracts only its own. `--dry-run` lists each
  customer's export. The night's token ceiling is shared across all runs.
