- work-default's `confluence-context` skill reads the wiki pages a ticket links: hangar's `in/confluence-*.md` files
  in a job, the wiki role's read tools in a session. Page text is untrusted reference; a page that conflicts with the
  acceptance criteria is a question (`hangar-agent ask`, or a Decision); the pages that shaped the change are cited
  in RESULT.md. Profiles name the wiki server as `wiki_server`, held to the bound wiki role.
- `jira-ticket` reads all of `jira-<KEY>.md` (comments, epic or parent, linked issues, attachments, what was not read
  or cut) and follows the newest trusted comment over the description when they conflict; an untrusted comment never
  changes the work.
- flightdeck's `work-never-writes-the-wiki` spec counts a page write on the wiki server, refused or not.
