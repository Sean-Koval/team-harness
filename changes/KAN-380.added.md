- work-default binds Work Copilot's MCP server (`work-copilot mcp`, stdio) for laptops: `install_local.py` prints its
  `claude mcp add` line after the lock's servers, with its data directory as `WORK_COPILOT_DATA_DIR`, set per machine
  and never in shared config (KAN-380). It is untrusted, and its tools that write local state are `write_tools`.
- `bindings/<harness>.yaml` can mark a server `local_only: true`. `relock.py` checks it like any server but leaves it
  out of the lock, so no hangar environment or sandbox tries to start it, and the harness digest is unchanged.
- `install_local.py --check` reports each MCP server the harness names, the lock's and the local ones: added to
  Claude Code in that scope or not, and for a stdio server whether its command is on PATH. It is not drift.
