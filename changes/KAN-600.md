- `build_generated.py`, `relock.py` and `render_envs.py` no longer import hangar: `scripts/harness_lockfile.py`
  computes the lock's digests and writes its bytes as hangar's `harness_lock` does, so a company builds its org
  overlay's revision with only Python and PyYAML. `install_local.py` uses the same module instead of its own copy.
  Promoting and `hangar harness check` still need hangar; `promote.py` says so in one line when hangar is missing.
  `tests/test_harness_lockfile.py` builds an overlay with hangar blocked and holds every function to hangar's own
  where hangar is installed.
