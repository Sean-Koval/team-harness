- `scripts/add_skill.py` brings a team work skill into the shared layer in one command: it checks the frontmatter (`name`, `description`), refuses Atlassian MCP tool names, secrets, e-mail addresses, hosts other than example.*, profile person and site values and words from a local deny list (`TEAM_HARNESS_DENY`), checks placeholders against the harness's profile, copies the skill with LF line ends, sets `harnesses: [..]` and writes a changelog fragment. `--check` runs the rules over every shared skill in CI (`tests/test_add_skill.py`); the teammate guide has an "Add a team work skill" section.
