- `scripts/work_copilot_overlay.py` writes a Work Copilot overlay (`work-copilot.overlay/v1`) from a harness's company
  overlay: its work site, knowledge space, Jira project and review room, with the profile's values where the org leaves
  them out. It normalises them to Work Copilot's formats and refuses anything else, naming the file and the field;
  `--at <commit>` reads them at a pinned revision. `install_local.py` prints the commands that write it and apply it
  with Work Copilot's own launcher, pinned to the revision it installs, and flags a placeholder org. The file goes
  to `team-harness/work-copilot-overlay.json` in your own config folder (`%APPDATA%`, `$XDG_CONFIG_HOME` or
  `~/.config`), never the current folder; `--overlay-out <file>` chooses another.
