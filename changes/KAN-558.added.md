- The work-system PR check reads the artifact check's receipt (rule 9, `artifact-receipt`). The PR needs a
  well-formed `team-harness.artifact-check/v1` receipt whose `passed` holds by the check's own rule. A run over its
  budget, a receipt whose cases don't add up to its verdict, and a receipt committed to git or changed by the PR fail.
  A missing receipt passes with a warning only under `allow-unverified`; `artifact-min-pass-rate` sets a floor.
