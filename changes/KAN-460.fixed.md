- On Windows without Git Bash, a guard's block now reaches Claude Code as exit 2. PowerShell turns a hook's exit 2 into 1, which Claude Code counts as a hook failure there, so the hook commands `install_local.py` writes for Windows end in `; exit $LASTEXITCODE`. Reinstall to get them.
- Each guard's block also prints the same reason as a PreToolUse deny on stdout, read alongside the exit 2.
- `install_local.py --apply` and `--check` now send each PreToolUse guard a call it can't read, and fail out loud unless the guard blocks it with exit 2 through the hook shell.
- On Windows a guard whose `py` can't start (uninstalled, off PATH) now blocks the call instead of letting it through. Its entry names PowerShell as its shell, says `"onFailure": "block"`, and its command exits 2 when `$LASTEXITCODE` is empty. The installer's tests that run a Windows guard's command need PowerShell, or `pwsh` off Windows.
