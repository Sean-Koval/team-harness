# Release on Thursdays

> [00:02:10] lead-example: Decision one: we release on Thursdays from now on. Tuesday releases kept colliding with the on-call handover.

## Context

Tuesday releases kept colliding with the on-call handover.

## Decision

## Consequences

Release day no longer overlaps the on-call handover.
